# Roadmap

SafeCut is built phase by phase. A phase is only ticked when its features are
implemented **and** verified — see [FEATURES.md](./FEATURES.md) for the evidence
behind each item.

---

## Phase 1 — Foundation ✅ (done)

- [x] Next.js 16 + TypeScript + Tailwind 4 + Zustand architecture
- [x] Project data model, pure timeline operations, undo/redo
- [x] IndexedDB storage (projects + media blobs) with auto-save
- [x] Dashboard: list, create, duplicate, delete, import/export project files
- [x] Editor workspace: media panel, canvas preview, properties, timeline
- [x] Media import with validation, metadata probing, thumbnails
- [x] Text clips, filters, transitions, keyframes, speed/freeze
- [x] Canvas-based export (MediaRecorder) with progress and cancel
- [x] 29 unit tests, typecheck, lint, production build

## Phase 2 — Captions, audio, scenes, FFmpeg ✅ (done)

- [x] Subtitle engine: SRT/VTT/TXT import + export, cue editor, 6 templates
- [x] Caption clips, karaoke highlight, word-by-word captions
- [x] Speech recognition via the browser Web Speech API (where available)
- [x] Waveforms (timeline + audio studio), decoded with Web Audio
- [x] Audio extraction from video, WAV/MP3 mix export
- [x] Silence detection + removal, noise reduction, fades, ducking
- [x] Scene detection with thumbnails, black frames, split at cuts
- [x] FFmpeg.wasm engine: MP4/MOV/WebM transcode with progress, cancel, fallback
- [x] Real-time export renderer (audio/video stay in sync)
- [x] Frame stepping, stronger snapping, 10 s auto-save, crash recovery
- [x] 75 unit tests + 17-check browser smoke suite

## Known limitations (current)

1. **Speech recognition** uses the browser's Web Speech API. Chrome/Edge may
   process audio in the cloud; timings are phrase-level, not word-level.
2. **EQ is preview-only.** Volume, fades and ducking are applied to exported
   audio; EQ currently affects playback only.
3. **Reverse playback** is stored as a flag; the exporter plays forward.
4. **Export is real time.** A 2-minute video takes about 2 minutes to record
   (plus FFmpeg encoding), because MediaRecorder captures as it plays.
5. **MOV/WebM FFmpeg paths** are implemented but only MP4 was verified end-to-end.
6. **4K export** depends on the device; expect dropped frames on low-end laptops.
7. **FFmpeg.wasm assets** (33 MB) are generated by `npm run setup:ffmpeg` and are
   not committed.
